# xui

前端技术学习与工具收集仓库，涵盖模板引擎、UI 框架、JS 工具库、Node.js 模块以及个人作品等内容。

## 目录结构

### 模板引擎

| 目录 | 说明 |
| --- | --- |
| `artTemplate` | 高性能 JavaScript 模板引擎（art-template 3.x），支持浏览器与 Node.js，提供预编译功能 |
| `BaiduTemplate` | 百度前端团队出品的轻量级 JS 模板引擎 |
| `doT` | doT.js —— 小巧快速的模板引擎，支持 V8 / 浏览器 / Node.js |
| `laytpl` | LayUI 生态中的超轻量模板引擎（约 1KB） |
| `sitjs` | 模板引擎相关项目（待补充） |

### UI 框架与组件

| 目录 | 说明 |
| --- | --- |
| `SUI-Mobile` | 阿里巴巴出品的移动端 UI 库（轻量，受 Framework7 启发） |
| `weui` | 基于微信 WeUI 的扩展组件库，附加 CSS/JS 组件，适用于公众号 / 移动端页面 |
| `jqueryplus` | jQuery + Zepto 插件合集，面向移动端 / 微信场景 |
| `zepto.fullpage` | 基于 Zepto 的移动端全屏滑动组件 |

### JavaScript 框架

| 目录 | 说明 |
| --- | --- |
| `jQuery` | jQuery 2.1.4 源码阅读与架构分析 |
| `vue` | Vue.js 框架源码学习 |
| `vue-router` | Vue.js 官方路由（适配 Vue 0.12.10+） |

### JS 工具库

| 目录 | 说明 |
| --- | --- |
| `JavaScript-MD5` | blueimp 出品的 JavaScript MD5 实现，支持浏览器、AMD 与 Node.js |
| `bytes.js` | 字节单位转换工具（如将 `1TB` 转换为字节数） |
| `move.js` | 基于 CSS3 的链式动画库 |

### Node.js 模块

| 目录 | 说明 |
| --- | --- |
| `node-browserify` | Browserify —— 让浏览器也能使用 Node.js 风格的 `require()` |
| `node-optimist` | Node.js 命令行参数解析库（已废弃，推荐迁移至 minimist / yargs） |

### 项目与资料

| 目录 | 说明 |
| --- | --- |
| `bc` | bc-vr 项目 —— Node.js 应用，包含微信 JSSDK 配置接口 |
| `projects` | 个人作品集（含 PC 端与 H5 项目） |
| `FE-Article` | 前端技术文章收集 |
| `nodejs+Express+Mongodb快速开发多人博客 pdf` | Node.js + Express + MongoDB 多人博客开发教程资料 |

## 快速开始

```bash
git clone https://github.com/bestXie/xui.git
cd xui
```

各子目录均为独立项目或学习资料，进入对应目录查看其 README 获取详细使用说明。
